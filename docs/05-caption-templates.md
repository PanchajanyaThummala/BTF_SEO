# 5. Caption Templates

Put the keywords in the first line, the value in the middle, and one question or CTA at the end. Hashtags go last, 5 at most.

## Tactical Breakdown
```
How {Team} beat {Opponent}'s press: tactical analysis 📐

{Team} kept building out through {detail}. Here's what {Manager} changed:
1️⃣ {point 1}
2️⃣ {point 2}
3️⃣ {point 3}

Would this work against {Rival}? 👇
Send this to a {Team} fan 📩

#footballtactics #tacticalanalysis #{team} #{competition} #beyondtheformation
```

## Formation Explained
```
{Formation} explained in 60 seconds ⚽ football tactics for beginners

✅ Strengths: {strength}
❌ Weakness: {weakness}
🏆 Best example: {Team} under {Manager}

Save this 📌 for your next FIFA/FC or Football Manager game.

#footballtactics #formation #{formation_tag} #footballmanager #beyondtheformation
```
